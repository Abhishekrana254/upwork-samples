The problem

Social posts, customer reviews, and email messages need a daily label for the dominant emotion: Happy, Sad, or Angry. The raw text is already in CSV files, one unique ID and one text field per row. The language is English only. The model has to be accurate enough to run unattended, simple to retrain when more labeled rows arrive, and able to run on a normal CPU. The hand-off is a short report of precision, recall, and F1, plus a demo script or notebook that reads a CSV and prints the labels.

Flow

  1. Read the CSV and keep the ID next to the text.
  2. Clean the English text: lower case, drop links, drop characters that are not letters.
  3. Fine-tune a small Hugging Face classifier on rows that already have a Happy, Sad, or Angry label.
  4. Score precision, recall, and F1 for each label on a held-out slice.
  5. Run the same clean-and-predict steps on a new CSV from a demo script.
  6. Retrain from the same script when a larger labeled file is added.

Files

  • clean.py normalises one text field. It does not assign an emotion.
  • train.py fine-tunes the Hugging Face classifier and writes a local model folder.
  • predict.py loads that folder and writes ID plus Happy, Sad, or Angry.
  • report.py prints precision, recall, and F1 for the three labels.
  • demo.ipynb runs clean, predict, and the report on one sample CSV.
  • README.md says how to install the CPU build and how to retrain.

Architecture

The CSV is the only input. Cleaning is a pure function, so the trainer and the daily run share it. The model folder is the only artifact the predictor reads. The report is computed from pairs of true label and predicted label, not from a printed screenshot. A row with empty text keeps its ID and gets no emotion, so the row count does not change. This page is a sketch of that workflow. It does not assume a labeled training file or a deployed service already exists.

Core step

import re

LABELS = ("Happy", "Sad", "Angry")

def clean_text(text):
    """English only: lower case, drop urls, keep letters and apostrophes."""
    text = str(text or "").lower()
    text = re.sub(r"https?://\S+", " ", text)
    text = re.sub(r"[^a-z'\s]", " ", text)
    return re.sub(r"\s+", " ", text).strip()

def class_scores(y_true, y_pred, label):
    """Precision, recall, and F1 for one emotion label."""
    tp = sum(1 for t, p in zip(y_true, y_pred) if t == label and p == label)
    fp = sum(1 for t, p in zip(y_true, y_pred) if t != label and p == label)
    fn = sum(1 for t, p in zip(y_true, y_pred) if t == label and p != label)
    precision = tp / (tp + fp) if (tp + fp) else 0.0
    recall = tp / (tp + fn) if (tp + fn) else 0.0
    f1 = (2 * precision * recall / (precision + recall)) if (precision + recall) else 0.0
    return {"label": label, "precision": precision, "recall": recall, "f1": f1}

def emotion_report(rows):
    """rows are dicts with keys label and pred. One score dict per emotion."""
    y_true = [row["label"] for row in rows]
    y_pred = [row["pred"] for row in rows]
    return [class_scores(y_true, y_pred, label) for label in LABELS]
