E-Commerce Automation Specialist Needed

Abhishek Rana. A sketch of how this build would go.

The problem

FCI London sells luxury furniture and needs product data to move from supplier websites and price lists onto the site without a person retyping each row. A scraper should pull descriptions, specifications, images, and prices. Price lists arrive as PDF, Excel, or CSV and have to become structured import files, including pricing combinations that follow currency changes. Images need resizing, compression, and format changes. A scheduled run should keep prices, inventory, and product details current.

Flow

  1. Scrape one supplier page into a raw table: sku, name, specs, image URL, and cost.
  2. Read that supplier's price list from Excel, CSV, or a text extract of the PDF.
  3. Apply the currency rate and write one import row per finish or size combination.
  4. Download each image, resize it, and save a compressed file the site can take.
  5. Write the import CSV and skip any row that fails a required-field check.
  6. Run the same steps on a schedule and log what changed.

Files

  • scrape.py uses Scrapy or BeautifulSoup to pull one supplier page into rows. It does not set prices.
  • prices.py reads the price list, applies the rate, and expands finish combinations.
  • images.py uses Pillow to resize, compress, and convert each product image.
  • import_csv.py writes the website import file and records rows that fail validation.
  • schedule.py runs the four steps on a timer so prices stay current.
  • README.md lists the supplier, the rate rule, and the command to run one pass.

Architecture

Each step reads a table and writes the next table. The scraper never sees the markup rule. The price step never downloads an image. The import file is the only artifact the website needs. A bad row is logged and left out, so one broken supplier line does not stop the file. The schedule calls the same functions the manual run calls. This page is a sketch of that pipeline. It does not assume the site import or the supplier feeds are already connected.

Core step

def money(value):
    """Strip currency marks and thousands separators. Return a float."""
    text = str(value).strip().replace(",", "")
    for mark in ("GBP", "USD", "EUR", "Rs", "£", "$"):
        text = text.replace(mark, "")
    return float(text.strip())

def expand_prices(rows, rate, markup):
    """One supplier row can list several finishes. Emit one import row for each."""
    out = []
    rate = float(rate)
    markup = float(markup)
    for row in rows:
        cost = money(row["cost"])
        price = round(cost * rate * (1 + markup), 2)
        finishes = [part.strip() for part in str(row.get("finishes") or "Standard").split("|")]
        finishes = [part for part in finishes if part]
        for finish in finishes:
            code = "".join(ch for ch in finish.upper() if ch.isalpha())[:3] or "STD"
            out.append({
                "sku": "%s-%s" % (str(row["sku"]).strip(), code),
                "name": str(row["name"]).strip(),
                "finish": finish,
                "cost": "%.2f" % cost,
                "price": "%.2f" % price,
                "image": str(row.get("image") or "").strip(),
            })
    return out
