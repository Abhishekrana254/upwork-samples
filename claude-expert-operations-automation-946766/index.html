Claude Expert, Operations Automation

A sketch of how the build would go. Abhishek Rana.

The problem

Daily operations still include repetitive manual work. The ask is a workflow that takes one of those items, uses the Claude API and a clear prompt, and returns a structured result that another system can accept over a webhook. API keys stay out of logs and out of the payload. Nothing here is running for this client yet. The first task still has to be named.

Flow

  1. An operations item arrives on an inbound webhook.
  2. The receiver checks a shared secret and keeps the raw text.
  3. Claude is called once and must return one structured action.
  4. If a required field is missing, the item waits for a person.
  5. Otherwise the action is posted to the downstream webhook.
  6. The log stores the action id and never the API key.

Files

  • webhook_in.py accepts the item, checks the inbound secret, and writes the raw text.
  • claude_action.py calls the Claude Messages API and forces one tool so the shape stays fixed.
  • schema.json is the tool input: action, summary, fields, and needs_review.
  • deliver.py posts that object to the outbound webhook only when needs_review is false.
  • .env.example names ANTHROPIC_API_KEY, INBOUND_WEBHOOK_SECRET, and OUTBOUND_WEBHOOK_URL. No real values.

Architecture

One Python process owns the path. The inbound webhook is the only door in. Claude is the only step that reads the item text, and a forced tool call is what makes the output structured. Delivery is a separate function so a review hold can stop the outbound call without losing the raw item. Secrets come from the environment. This is the shape of the build, not a system that already exists.

Core step

import json
import os
import urllib.request

def structured_action(item_text: str) -> dict:
    schema = json.load(open("schema.json"))
    body = {
        "model": "claude-sonnet-4-5",
        "max_tokens": 800,
        "system": (
            "Turn one operations item into one action. "
            "Use only facts present in the item. Call record_action once."
        ),
        "tools": [{
            "name": "record_action",
            "description": "Record the next operations action.",
            "input_schema": schema,
        }],
        "tool_choice": {"type": "tool", "name": "record_action"},
        "messages": [{"role": "user", "content": item_text}],
    }
    req = urllib.request.Request(
        "https://api.anthropic.com/v1/messages",
        data=json.dumps(body).encode(),
        headers={
            "content-type": "application/json",
            "x-api-key": os.environ["ANTHROPIC_API_KEY"],
            "anthropic-version": "2023-06-01",
        },
    )
    with urllib.request.urlopen(req, timeout=60) as resp:
        payload = json.loads(resp.read().decode())
    block = next(b for b in payload["content"] if b["type"] == "tool_use")
    return block["input"]
