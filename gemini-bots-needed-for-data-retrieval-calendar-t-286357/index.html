Gemini Bots Needed for Data Retrieval, Calendar & TestingWe have 3 use cases for a Gemini bot: 1) Send out reminders late afternoon for next-day meetings on Google calendar, 2) log into a transportation management system, and retrive load data, this needs to be modular, so we can use some of the same bot for other systems, 3) testing functionality of the Private Fleet Net Zero System, complex with test fleets and test buyers, all done with trustworthy Gemini, not other questionabile AI techThe bot also has to record activity and report on successes and failed attempts

Files

intake.py reads the request and writes one row. worker.py is the only file that calls the model. page.js renders the result and never holds a secret.

Architecture

The row is the contract. The worker takes that row, runs the step, and writes the result back. A second business does not read the first business's row. The page only polls status.

def run_step(row):
    text = str((row or {}).get("text") or "").strip()
    if not text:
        return {"ok": False, "error": "empty"}
    return {"ok": True, "job": "Gemini Bots Needed for Data Retrieval, Calendar & Testing", "text": text, "state": "done"}
