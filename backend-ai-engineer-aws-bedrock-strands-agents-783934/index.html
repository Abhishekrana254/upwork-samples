Architecture

The row is the contract. The worker takes that row, runs the step, and writes the result back. A second business does not read the first business's row. The page only polls status.

def run_step(row):
    text = str((row or {}).get("text") or "").strip()
    if not text:
        return {"ok": False, "error": "empty"}
    return {"ok": True, "job": "Backend AI Engineer (AWS Bedrock + Strands Agents)", "text": text, "state": "done"}
