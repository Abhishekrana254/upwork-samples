Indian Speech-to-Text Model Customization

Abhishek Rana. A sketch of how this build would go.

The problem

The speech stack has to stay fully open source and run on local Windows GPU servers with CUDA and PyTorch. The target languages are Hindi, Tamil, Bengali, Marathi, Telugu, Kannada, and Gujarati. Whisper, AI4Bharat Indic models, and Vanni from IISc are the starting engines. The lift that matters is word error rate, latency, and memory: at least five languages should beat the base model by 10 percent relative WER on the internal test set, and a 15-second clip should transcribe in under two seconds on an RTX A4000.

Flow

  1. Freeze one internal test set per language: wav files plus reference text.
  2. Score the untouched base checkpoint for WER, seconds per clip, and peak GPU memory.
  3. Fine-tune that checkpoint on in-domain audio and add the domain word list for that language.
  4. If a 15-second clip is still over two seconds, quantise or export to ONNX and re-time it on the A4000.
  5. Serve the chosen weights from a container with a REST endpoint and a gRPC endpoint.
  6. Write one row per language: base WER, tuned WER, latency, and memory.

Files

  • train.sh sets the CUDA device, the language, and the open checkpoint, then starts the run.
  • finetune.ipynb is the PyTorch fine-tune for Whisper, an Indic model, or Vanni. One language per notebook section.
  • wer.py computes word error rate and records latency and peak GPU bytes for one clip.
  • serve.py is the FastAPI REST endpoint. It loads the local weights and returns text.
  • grpc_server.py is the same transcribe call over gRPC.
  • Dockerfile packages the inference service for the on-prem GPU host.
  • GETTING_STARTED.md tells the internal team how to retrain one language later.

Architecture

Training and serving stay apart. The notebook writes a weights folder per language. The container only reads that folder. No call leaves the GPU server. The benchmark script is the gate: a language is kept only when relative WER drops by at least 10 percent and a 15-second clip finishes in under two seconds. Languages that miss the bar stay on the base checkpoint and are listed that way in the report. This page does not assume those weights or that test set already exist.

Core step

import time
import torch

def word_error_rate(reference, hypothesis):
    """Edits divided by reference length. Empty reference returns 0."""
    ref = reference.split()
    hyp = hypothesis.split()
    n, m = len(ref), len(hyp)
    if n == 0:
        return 0.0
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        dp[i][0] = i
    for j in range(m + 1):
        dp[0][j] = j
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            cost = 0 if ref[i - 1] == hyp[j - 1] else 1
            dp[i][j] = min(dp[i - 1][j] + 1, dp[i][j - 1] + 1, dp[i - 1][j - 1] + cost)
    return dp[n][m] / n

def score_clip(model, waveform, reference, language):
    """WER, wall time, and peak GPU memory for one clip on the local device."""
    if torch.cuda.is_available():
        torch.cuda.reset_peak_memory_stats()
        torch.cuda.synchronize()
    start = time.perf_counter()
    text = model.transcribe(waveform, language=language)["text"]
    if torch.cuda.is_available():
        torch.cuda.synchronize()
    elapsed = time.perf_counter() - start
    mem = torch.cuda.max_memory_allocated() if torch.cuda.is_available() else 0
    base = float(reference.get("base_wer") or 0)
    wer = word_error_rate(reference["text"], text)
    relative = (base - wer) / base if base else 0.0
    return {
        "language": language,
        "wer": wer,
        "relative_drop": relative,
        "seconds": elapsed,
        "under_two_seconds": elapsed < 2.0,
        "gpu_bytes": mem,
    }
