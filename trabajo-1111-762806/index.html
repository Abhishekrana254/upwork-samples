First AI scripts in Spanish

Abhishek Rana. A sketch of how the build would go.

The problem

The student wants a serious start in artificial intelligence, preferably in Spanish: the ideas behind current models, then a first set of Python scripts using TensorFlow or PyTorch. Machine Learning, natural language, and computer vision are all still open, so the three areas need a plain comparison before one track is chosen. The hand-off is live sessions for explanation and questions, with a recording, practical exercises on small documented datasets, and a personal roadmap for after the course. The work should show a result that can be rerun in the first week.

Flow

  1. Compare one small example from Machine Learning, natural language, and computer vision.
  2. Pick the starting track together.
  3. Train a tiny model in plain Python so the update step is visible.
  4. Move that same dataset into TensorFlow or PyTorch.
  5. Record the session, keep the exercise, and write the roadmap in Spanish.

Files

  • semana1_lineal.py trains a small linear model on six short Spanish sentences and prints positivo or negativo.
  • semana2_pytorch.py runs the same sentences in PyTorch once the plain loop is clear. A TensorFlow twin is the alternative if that library is chosen.
  • notas_ml.md, notas_pln.md, and notas_vision.md are the three short comparisons, in Spanish.
  • datos_frases.csv is the tiny documented dataset for week one.
  • hoja_de_ruta.md is the personal roadmap and the suggested resources after the sessions.
  • README.md says how to rerun the script and where the recording link goes.

Architecture

Week one stays in plain Python so each weight update can be read on one screen. The dataset is six Spanish sentences and a positivo or negativo label. After that script runs, the same rows move into PyTorch or TensorFlow, which is the first library exercise. Three short notes compare the areas before the track is locked. Each live session is recorded. The roadmap is a separate note for what to study next. This is a sketch of those materials. It is not a finished course.

Week-one trainer

VOCAB = ["bueno", "malo", "encanta", "odio", "util", "lento"]

def tokens(text):
    cleaned = []
    for raw in text.lower().split():
        word = raw.strip(".,;:!?")
        if word:
            cleaned.append(word)
    return cleaned

def vector(text):
    words = set(tokens(text))
    return [1.0 if word in words else 0.0 for word in VOCAB]

def sigmoid(z):
    e = 2.718281828 ** (-z if z >= 0 else z)
    return (1.0 / (1.0 + e)) if z >= 0 else (e / (1.0 + e))

def train(rows, labels, steps=400, lr=0.8):
    weights = [0.0] * len(VOCAB)
    bias = 0.0
    for _ in range(steps):
        for features, label in zip(rows, labels):
            score = bias
            for weight, value in zip(weights, features):
                score += weight * value
            error = sigmoid(score) - label
            weights = [weight - lr * error * value for weight, value in zip(weights, features)]
            bias -= lr * error
    return weights, bias

def predict(weights, bias, text):
    score = bias
    for weight, value in zip(weights, vector(text)):
        score += weight * value
    return 1 if sigmoid(score) >= 0.5 else 0

Trained on "el curso es bueno y util", "odio este libro malo", "me encanta porque es util", "es lento y malo", "un libro bueno", and "muy lento", the script labels all six correctly. "encanta y bueno" comes back positivo. "odio y lento" comes back negativo. Words such as bueno and encanta get positive weights. malo, odio, and lento get negative weights.
