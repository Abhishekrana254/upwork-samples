PDF table text dump

Abhishek Rana. A sketch of how the build would go.

The problem

A set of PDFs holds well-formed tables. Every page uses the same columns, so finding the columns should be simple. The needed output is the raw text only: clean plain-text files that keep line breaks, with no Excel and no CSV. Each row should stay intact and in the original order. Because the layout does not change, the dump should be accurate enough to edit later without a manual cleanup pass. Python is fine, including Camelot, Tabula, or a small parser. A short note should explain the method so it can be rerun or adapted.

Flow

  1. Open one PDF and confirm the columns sit in the same places on every page.
  2. Read each word with its horizontal and vertical position.
  3. Join words that share a horizontal band into one line, left to right.
  4. Write one .txt per PDF, in that row order.
  5. Check a few pages against the source, and leave a short method note.

Files

  • extract.py reads a PDF into word positions. Camelot or Tabula can supply those positions when the grid is ruled. The function below is what keeps each row intact.
  • rows.py groups words into lines and writes plain text. It does not write CSV or Excel.
  • out/ holds one .txt per source PDF, with the same base name.
  • README.md is the method note: the library, the band tolerance, and how to rerun the script.

Architecture

The PDF is read as words with an x and a y, not as a spreadsheet. Words whose y values fall inside a small band are one visual row. Inside that band they are ordered by x, then joined with a pipe so the columns stay visible in a text file. A new band starts a new line, so a later row cannot merge into an earlier one. Pages are appended in order, and one .txt is written per PDF. The README records the band size so a later edit can loosen or tighten it. This is a sketch of that dump. It is not a claim that these PDFs have already been converted.

Keep each row on one line

def table_text(words, y_tol=3.0):
    groups = []
    ordered = sorted(words, key=lambda word: (-word["y"], word["x"]))
    for word in ordered:
        if not groups or abs(groups[-1][0]["y"] - word["y"]) > y_tol:
            groups.append([word])
        else:
            groups[-1].append(word)
    lines = []
    for group in groups:
        group.sort(key=lambda item: item["x"])
        lines.append(" | ".join(item["text"] for item in group))
    return "\n".join(lines)

Words for Name, Qty, and Price, then Bolt, 2, and 1.50, then Nut, 4, and 0.25, come out as three lines. Qty is one unit off the header line and 1.50 is one unit off the Bolt line. Both stay on their row because the band is 3. The first line is the header, because it sits higher on the page. The text is:

Name | Qty | Price
Bolt | 2 | 1.50
Nut | 4 | 0.25
