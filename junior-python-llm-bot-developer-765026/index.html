The problem

Routine company work still needs a person to log in, collect data, decide what to do, and type the result into a web app, an old desktop tool, or a cloud service. The bots should do that loop without a manual step in the middle, and each routine should be able to use a local model or a hosted one.

Flow

  1. A FastAPI endpoint starts one named routine and stores its status.
  2. Playwright opens the web app, logs in, and collects the rows for that routine.
  3. The same prompt is sent to a local llama.cpp server or to the OpenAI API, chosen by a flag on the routine.
  4. The bot acts: a REST call for the cloud service, and PyAutoGUI only for the desktop tool that has no API.
  5. The result is written back to the web app or the cloud hook, and the status row is marked done.
  6. Setup notes and a short screen-share cover how to run that one routine again.

Files

  • app.py is the FastAPI app. It starts a run and returns status. It does not call a model.
  • bot.py logs in with Playwright, collects the rows, and calls the hand-off.
  • llm.py switches one prompt between the local llama.cpp server and the OpenAI API.
  • desktop.py runs the few PyAutoGUI clicks the legacy desktop tool still needs.
  • cloud.py posts the result JSON to the cloud service you already use.
  • README.md is the setup: env vars, how to start llama.cpp, and how to run one routine.

Architecture

Each routine is one row: login URL, what to collect, whether the model is local, and where the result goes. bot.py is the only file that drives the browser. llm.py is the only file that talks to a model. The web app, the desktop tool, and the cloud hook stay separate callers, so a second routine does not share the first routine's session. The page only polls status. Nothing here assumes those systems have already been wired up.

Core step

import json
import urllib.request

def complete(prompt, use_local, local_url, openai_key, model):
    """One prompt, either llama.cpp on this machine or the OpenAI API."""
    if use_local:
        body = json.dumps({
            "prompt": prompt,
            "n_predict": 256,
            "temperature": 0.1,
        }).encode()
        req = urllib.request.Request(
            local_url.rstrip("/") + "/completion",
            data=body,
            headers={"Content-Type": "application/json"},
        )
        with urllib.request.urlopen(req, timeout=60) as resp:
            return json.loads(resp.read().decode())["content"].strip()
    body = json.dumps({
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.1,
    }).encode()
    req = urllib.request.Request(
        "https://api.openai.com/v1/chat/completions",
        data=body,
        headers={
            "Content-Type": "application/json",
            "Authorization": "Bearer " + openai_key,
        },
    )
    with urllib.request.urlopen(req, timeout=60) as resp:
        data = json.loads(resp.read().decode())
    return data["choices"][0]["message"]["content"].strip()

def run_once(page, task):
    """Log in, collect the rows, ask the chosen model, post the result."""
    page.goto(task["login_url"])
    page.fill(task["user_sel"], task["username"])
    page.fill(task["pass_sel"], task["password"])
    page.click(task["submit_sel"])
    page.wait_for_url(task["after_login"])
    rows = page.locator(task["row_sel"]).all_inner_texts()
    prompt = "Turn these rows into the next action.\n" + "\n".join(rows)
    answer = complete(
        prompt,
        task["use_local"],
        task["llama_url"],
        task["openai_key"],
        task["model"],
    )
    payload = json.dumps({"routine": task["name"], "rows": rows, "answer": answer}).encode()
    req = urllib.request.Request(
        task["cloud_hook"],
        data=payload,
        headers={"Content-Type": "application/json"},
    )
    with urllib.request.urlopen(req, timeout=30) as resp:
        ok = resp.status == 200
    return {"ok": ok, "rows": len(rows), "answer": answer}
