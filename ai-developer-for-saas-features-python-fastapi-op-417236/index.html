Architecture

The row is the contract. The worker takes that row, runs the step, and writes the result back. A second business does not read the first business's row. The page only polls status.

def run_step(row):

    if not text:

    return {"ok": True, "job": "AI Developer for SaaS Features (Python, FastAPI, OpenAI)", "text": text, "state": "done"}
